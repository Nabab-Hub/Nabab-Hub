### ✨ About Me

- 🌱 **Exploring & Researching:** Multi-Agent LLM Orchestration & Edge ML Deployment
- 🎓 **Education:** B.Tech in Computer Science & Engineering
- 💬 **Ask Me About:** Next.js, FastAPI, YOLOv8, PyTorch, React, Python, Cloud Architectures
