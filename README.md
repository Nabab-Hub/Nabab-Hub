### ✨ About Me

👋 Hey there! I'm **Sk Ahidulla**, a passionate **Full Stack & Applied Machine Learning Engineer** based in West Bengal, India.

I love architecting end-to-end intelligent systems — from training real-time Computer Vision (YOLOv8) & Voice AI models to crafting sleek, responsive web applications with Next.js, React, and TypeScript.

- 🔭 **Currently Building:** Real-time Computer Vision Systems & Autonomous AI Voice Agents
- 🌱 **Exploring & Researching:** Multi-Agent LLM Orchestration & Edge ML Deployment

- ⚡ **Fun Fact:** *I debug neural networks by day and optimize render trees by night! ☕*
